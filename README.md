# Interactive Portfolio

React + Vite portfolio with profile portrait, architecture diagram, responsive mobile navigation, project filters, scroll progress, reveal animations, copy-email action, and architecture lightbox.

Run with `npm install` then `npm run dev`. Build with `npm run build`.

Edit `src/App.jsx` for content and `src/style.css` for styling. Images are in `public/images/`.

AI/ML anomaly detection and failure prediction are described as planned future capabilities, not currently deployed features. Add verified repository/demo URLs before publishing.
